# Sentence Lab — 5형식 문법 구조 학습도구

## 포함된 기능
- 학습자/강사 역할 선택
- 1~5형식 설명과 예문 탭
- 다섯 형식을 모두 열면 활성화되는 10문항 레벨테스트
- 정답 시 난이도 상승, 오답 시 같은 난이도 유지
- 문항별 정오답, 한국어 해설, 문장 성분 분석
- 초급/중급/고급 등급, 테스트 날짜별 결과 복습
- 강사 대시보드, 학습자별 점수 요약 및 피드백
- FastAPI + SQLite 서버 저장
- OPENAI_API_KEY가 설정되면 GPT API로 새로운 문장/해설 생성; 키가 없거나 API 오류면 내장 문제 풀로 자동 대체

## 로컬 실행
Python 3.10 이상 권장.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
# 선택: 환경변수 OPENAI_API_KEY를 설정하면 GPT 문장 생성 활성화
uvicorn main:app --reload
```
브라우저에서 http://127.0.0.1:8000 을 여세요.

## 인터넷에 공개하기 (Render 예시)
1. 이 압축파일을 풀고 GitHub 저장소를 새로 만들어 파일들을 업로드합니다.
2. Render 계정에서 **New + → Blueprint**를 선택하고 저장소를 연결합니다.
3. `render.yaml` 설정을 확인해 배포합니다.
4. Render 대시보드의 Environment에서 `OPENAI_API_KEY`를 비밀 환경변수로 등록합니다. API 키를 HTML/JavaScript 파일에 넣지 마세요.
5. 공유할 `https://...onrender.com` 주소가 만들어지면 그 주소를 학습자/강사에게 전달합니다.

### 데이터베이스 영속성 주의
SQLite 파일은 실행 환경에 따라 재배포/재시작 시 사라질 수 있습니다. 실제 수업 데이터 보존을 위해서는 Render의 영구 디스크에 `DATABASE_PATH`를 연결하거나 PostgreSQL로 이전해야 합니다. 무료 호스팅의 절전/가용성 제한도 확인하세요.

## 중요: 현재는 공유용 베타
이 버전은 **닉네임 기반**이며 회원가입/로그인과 강사별 권한 인증은 구현되어 있지 않습니다. 따라서 공개 인터넷에 배포할 때는 민감한 개인정보를 입력하지 말고, 실제 학생의 평가자료를 운영하기 전에는 계정 인증, 강사-학생 연결 코드, 접근제어, 백업, 개인정보 처리 안내를 추가하세요. GPT 생성 문장은 자동 생성 특성상 오류 가능성이 있으므로 실제 성적 평가에 사용하기 전에 교사가 검토하는 것을 권장합니다.

## 레벨 기준
- 0–4개 정답: 초급
- 5–7개 정답: 중급
- 8–10개 정답: 고급

이 프로젝트는 학습용 MVP이며, 학교/기관의 공식 평가 시스템을 대체하지 않습니다.
